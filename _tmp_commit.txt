retrieval: optional recent-tail append, default off

Streaming questions ask about the conversation that is still arriving, and a purely
similarity-ranked list can miss "what did I just say". AML_RECENT_TAIL=N appends the
N newest turns AFTER the ranked list: it never displaces a ranked item and the answer
budget (117k tokens against our ~15k) has room, so the downside is limited to the
tokens it spends. Default 0 until a smoke run can measure streaming.

Also note for later: LongMemEval oracle cannot judge ranking (12.7 items returned of
~23 turns per instance ? the haystack fits), so LoCoMo-Refined stays the ranking corpus.
